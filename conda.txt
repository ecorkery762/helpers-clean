1. Create environment
   ==================

conda activate geo

conda remove --name geo --all

conda info --envs

conda create -help

2.2.2 Create YML and recreate environment later

conda env export --name finance > environment.yml            # will include conda dependencies for MAC current osx-64 platform;
conda env export --from-history > environment-history.yml    # packages only, will re-create anywhere
conda env create -f environment.yml

do both exports so that you have

finance-gold/
├── environment.yml
└── environment-history.yml

ISSUES:
=======

Issue 1:

conda create --name geo python=3.14   # 1.14 was NOT installed on the laptop (python --version)

  Issue:
    Your Miniconda installation is running as osx-64 (Intel/x86_64), and the defaults channel you're
    using doesn't currently have a Python 3.14 package for that platform.

    That's why Conda says:
    PackagesNotFoundError: python=3.14

  Checks:
    uname -m   ... gives x86_64 which is correct

  Solution:
    switch to 1.13 OR conda create --name finance -c conda-forge python=3.14 ... This was done and worked.
    ChatGPT: Conda-forge may have a Python 3.14 build for osx-64 even though your defaults channel doesn't
