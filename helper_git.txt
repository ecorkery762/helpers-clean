Appendix 1: Git Push personal access token


        Git fails authentication with:
        remote: Invalid username or token. Password authentication is not supported for Git operations.
        fatal: Authentication failed for 'https://github.com/ecorkery762/helpers.git/'

        This error is clear and very common 👍
        GitHub no longer allows password authentication for git push over HTTPS. You must use either a
        Personal Access Token (PAT) or SSH.

    Git push - PAT
        Get the PAT:
        Github: https://github.com/settings/profile [from profile on top RHS]
        Github: developer settings which is last on the list-menu on the LHS of settings
        Personal access token (classic)
            Custom to 2 days and note password use
            repo boxes highlighted [the top one - leave rest alone]
            generate and save (think can generate another one if required)
            save token to notepad as will not see again

    Private repo created
    git clone https://PAT@github.com/ecorkery762/retail-streamlit.git
