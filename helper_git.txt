2. Basic GIT commands

-------------------

LOCAL DIRECTORY
      │
      │ git add
      ▼
   Git index
      │
      │ git commit
      ▼
 Git repository
      │
      │ git push
      ▼
    GITHUB

--------------------

  Local (master branch)
  - git clone link from github
  - git status and git init
  - edit a file
  - save locally (working directory)

      git branch --show-current       # check the branch
      git status
      git remote -v

      git add helper_git.txt
      git commit -m "first attempt for helper_git.txt"      # commit f991bc15bc863a806ce235143496d43efdc2a325 (HEAD -> main)
      git push -u origin main [Matt Harrison recommends]    # commit f175e5ccfcc9113c3c6439e2523a5785e07a12b9 (origin/main)

  - check commit difference
      git diff file.txt                 # last commit verses latest unstaged file
      git diff --staged helper_git.txt  # last commit verses latest   staged file
      git diff hash1 hash2              # diff of two committed files
      git diff HEAD HEAD~1              # diff of two committed files

  - restoring a file
      git restore --staged helper_git.txt            # staged file
      git checkout HEAD~1 [or hash]-- report.md      # committed file

  - restoring a hash or commit
      git revert

Appendix 1: Git Push personal access token


        Git fails authentication with:
        remote: Invalid username or token. Password authentication is not supported for Git operations.
        fatal: Authentication failed for 'https://github.com/ecorkery762/helpers.git/'

        This error is clear and very common 👍
        GitHub no longer allows password authentication for git push over HTTPS. You must use either a
        Personal Access Token (PAT) or SSH.
